# JURNAL PROMPT & LOG MENTAH PENGEMBANGAN BLOKUMA

================================================================================
SECTION 1: JURNAL PROMPT BERDASARKAN KATEGORI
================================================================================

1. Ide/PRD:
   Prompt:
   "Rancang pembaruan arsitektur komprehensif khusus fitur 'Dongeng Generator' dari Kode Anak (Storyfication) untuk siswa SD Kelas 1-4.
   - Masalah: Koding sering terasa kaku dan matematis bagi anak-anak usia dini.
   - Cara Kerja AI: Setelah anak selesai membuat project atau menyelesaikan misi, AI akan melihat kode tersebut dan menyulapnya menjadi cerita mini/dongeng petualangan imajinatif. Contoh: 'Hari ini, Pahlawan [Nama Siswa] membuat mantra ajaib bernama Loop. Karena mantra itu, naga merah bisa menari 5 kali tanpa lelah! Hebat!'
   - Model yang Cocok: openai/gpt-oss-120b (Untuk merangkai imajinasi dan cerita yang kaya).
   - Backend Architecture: Tambah Serverless Edge Function baru kiko-story-generator di Supabase, deploy dari CLI tanpa error, terhubung dengan real data dan fallback engine 0ms."

2. Debugging:
   Prompt:
   "Lakukan investigasi dan perbaikan pada panggung koding Playground: Maskot Kiko tidak merender aset gambar dari /images/robot.webp dan animasi CSS-nya tidak berjalan. Analisis konflik antara inline style transform translateX dengan CSS Keyframe Animation, serta perbaiki kesalahan case-sensitivity path gambar di dev server Vite."

3. Audit & optimasi:
   Prompt:
   "Perbarui navigasi aplikasi agar saat browser di-refresh di halaman mana pun, pengguna tetap berada di halaman aktif tersebut tanpa terlempar atau kembali ke halaman lain. Serta hapus menu Pengaturan dari daftar utama sidebar dan pindahkan Pengaturan Profil & Logout ke Popover Card Profil Siswa di bagian bawah sidebar."

4. Finishing:
   Prompt:
   "Standarisasi seluruh antarmuka maskot Robot Kiko di seluruh halaman aplikasi (Landing Page, Login, Register, Dashboard, Playground, Lesson Detail, dan Hint Dialog) menggunakan aset teroptimasi /images/Robot.webp yang dilengkapi event-handler onError fallback otomatis serta tambahkan tombol '← Kembali' di setiap halaman."

5. Bebas:
   Prompt:
   "Integrasikan KikoStoryGeneratorModal di halaman Playground agar siswa dapat menyulap balok koding menjadi dongeng ajaib secara interaktif dilengkapi fitur Text-to-Speech audio '🔊 Suara Kiko Mendongeng'."

- Added `supabase/functions/kiko-smart-hint/index.ts`: Mengembangkan Deno/TypeScript Serverless Edge Function yang mengeksekusi Socratic Prompting berbasis model LLM `qwen/qwen3.8-27b` dengan Socratic Fallback Rule Engine otomatis.

- Added `components/ui/KikoSmartHint.jsx`: Membangun komponen UI Pop-up Maskot Kiko interaktif lengkap dengan penyesuaian usia (`SD 1-2`, `SD 3-4`, `SD 5-6`) serta Text-to-Speech Web Speech API (`id-ID`).
- Updated `app/(student)/app/playground/page.jsx`: Mengintegrasikan Kiko Smart Hint Widget dengan tracking automatik pada percobaan eksekusi gagal anak.
