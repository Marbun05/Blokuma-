================================================================================
# 02 DOCS ACUAN AI AGENT — BLOKUMA CODEBASE SPECIFICATION (VITE + REACT JSX RUNNER)
================================================================================

1. CODEBASE ARCHITECTURE & TECH STACK
--------------------------------------------------------------------------------
Framework      : React 19 + Vite Runner (`vite.config.js` / `@vitejs/plugin-react`)
Routing        : React Router DOM (`react-router-dom` Client SPA Routing)
Styling        : Tailwind CSS, Framer Motion, Lucide React
State          : Zustand
Backend / DB   : Supabase (Auth, PostgreSQL, Row Level Security)
Deployment     : Vercel / Static Web Host
Testing        : Vitest

2. STRICT FOLDER STRUCTURE & EXTENSIONS
--------------------------------------------------------------------------------
src/           : Application root (`main.jsx`, `App.jsx`, `index.css`)
src/components : Reusable React JSX components (.jsx)
app/           : Route page components (.jsx / .js) grouped by features
engine/        : Core Visual Coding AST Parser, Validator, Runtime, Rule Engine, Code Generators (.js)
domain/        : Entity schema constants and domain logic (.js)
services/      : Supabase Data Access Services (.js)
store/         : Zustand State Stores (.js)
supabase/      : Migrations SQL, Seed SQL, Config
tests/         : Unit Test Suites (.test.js / .test.jsx)

3. NAMING & VIBE CODING CONVENTIONS
--------------------------------------------------------------------------------
Files          : kebab-case.js / kebab-case.jsx
Components     : PascalCase (e.g., StudentSidebar, ProjectCard)
Functions      : camelCase (e.g., generateGuidedFeedback, parseBlockList)
Constants      : UPPER_SNAKE_CASE (e.g., PALETTE_BLOCKS, USER_ROLES)
Runner         : `npm run dev` launches Vite + React JSX runner server.

4. CURRENT IMPLEMENTATION STATE
--------------------------------------------------------------------------------
Status         : Fully configured with Vite + React JSX Runner & React Router DOM.
AST Engine     : Block AST, Rule Engine (Guided Debugger), Stage Execution, JS/Python Generators in engine/.
Grade Adaptive : Grade 1-2 (Phase A: Dunia Ikon & Suara), Grade 3-4 (Phase B: Dunia Blok & Logika), Grade 5-6 (Phase C: Dunia Algoritma & Game).
Routes         : Full Client SPA Routing configured in `src/App.jsx`.
