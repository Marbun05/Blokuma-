================================================================================
SECTION 1: HIGH-LEVEL VIBE CODING PROMPTS
================================================================================

1. Arsitektur Data Dinamis & Migrasi Database:
   Prompt:
   "Rancang lapisan data (*data layer*) yang *seamless* untuk modul Playground, Galeri, dan Achievements. Hilangkan seluruh *state* matriks data *hardcode* lokal. Lakukan migrasi struktur data utama ke PostgreSQL di Supabase, terapkan kebijakan RLS yang ketat, dan pastikan antarmuka melakukan *hydration* secara dinamis dari database untuk mencapai Single Source of Truth (SSOT). Buatkan juga panel Admin CRUD untuk mengelola data master ini tanpa perlu menyentuh kode."

2. Refaktor Fluid UI & Layout:
   Prompt:
   "Lakukan refaktor pada arsitektur *layout* global demi menghadirkan pengalaman navigasi yang bebas hambatan (*frictionless*). Terapkan *sidebar* yang *sticky* dan dapat di-*scroll* secara independen dari konten utama. Berikan batas ruang aman (safe-area constraints / bottom paddings) pada kontainer utama guna menjamin tata letak yang *pixel-perfect* dan bebas *overlap* di seluruh ukuran layar mobile maupun desktop."

3. AI Edge Storyfication Engine:
   Prompt:
   "Desain sebuah mesin AI Storyfication asinkronus berlatensi rendah menggunakan Supabase Edge Functions. Integrasikan model openai/gpt-oss-120b untuk menelan (ingest) struktur balok koding anak dalam format AST (Abstract Syntax Trees) dan menyintesisnya menjadi petualangan naratif yang sangat imajinatif dan terpersonalisasi. Pastikan UI terhubung secara mulus (*seamless bridging*) lengkap dengan mekanisme *modal fallback* yang elegan."

4. Penanganan Aset & Sinkronisasi Animasi:
   Prompt:
   "Lakukan investigasi dan tuntaskan *bottleneck* perenderan pada aset Maskot. Sinkronkan *keyframe animations* Tailwind dengan transformasi CSS *inline* dengan cara merefaktor hierarki DOM menjadi sistem *inner/outer wrappers* untuk mencegah *layout shifting*. Implementasikan fungsi *onError fallbacks* otomatis pada gambar untuk menjaga estetika UI agar tetap sempurna (*flawless*)."

5. Persistensi Sesi & Navigasi Bersih:
   Prompt:
   "Tingkatkan DX/UX perutean (routing) dengan merancang persistensi sesi yang ketat. Pasang sebuah Auth Listener pada *root* React guna mencegah hilangnya *state* saat terjadi *hard reload* di browser. Sederhanakan *sidebar* dengan mengekstraksi aksi Pengaturan dan Logout ke dalam komponen Profile Popover Menu yang modern dan terdeklarasi rapi."
