3. GROUND RULES & ENGINEERING STANDARDS
- 100% Pure Database SSOT (Zero LocalStorage, Zero Dummy Data): Seluruh profil, rombel kelas, progres 6 pulau, XP, karya, dan laporan disimpan dan diambil langsung dari database Supabase PostgreSQL. Tidak ada data angka dummy yang di-hardcode.
- Dynamic Terminal Seeder (`scripts/seed-rombels.js`): Seeder otomatis untuk rombel kelas yang dieksekusi via terminal (`npm run seed:rombels`) untuk memastikan tabel `public.classrooms` selalu terisi data valid.
- High Concurrency & Fast Data Batching (< 50 ms): Pengambilan data siswa menggunakan Single Batch Parallel Query (Promise.all dengan .in('id', studentIds)), In-Memory Cache (TTL 15 detik), serta pola SWR Background Revalidation agar aplikasi berkinerja secepat kilat untuk ribuan pengguna bersamaan.
- Scaled XP & Adaptive Curriculum:
  * Fase A (SD 1–2): Algoritma & Sekuensial Arah (Maju, Mundur, Kanan, Kiri).
  * Fase B (SD 3–4): Looping & Kondisional (Ulangi 3x, Jika Ada Rintangan Maka Lompat).
  * Fase C (SD 5–6): Variabel & Fungsi Dasar (Skor = Skor + 10, Fungsi PukulGong).
  * Scaled XP: +100 Base XP per pulau tuntas + +25 XP Bonus untuk efisiensi kode terpendek & pemecahan kasus detektif.
- Printable Rapor PDF Resmi Kurikulum Merdeka (KKM 75): Menghasilkan dokumen Rapor PDF siap cetak A4 via window.print() dengan 3 Pilar Penilaian Utama (Nilai Coding, Nilai Logic, Nilai Math & Kesiapan Lomba/COC) murni dari data riil tanpa inflasi nilai.
- Event-Driven Reactive UX: Menggunakan CustomEvent('student_progress_updated') agar setiap kenaikan XP dan pembukaan pulau baru membalas secara instan di Beranda Siswa, Peta Petualangan, Lemari Lencana, Portal Orang Tua, dan Hub Guru tanpa reload browser.
- Full-Width Admin Control & Custom Quiz Creator: Dashboard Admin edge-to-edge dengan 4 fitur moderasi (Review Laporan Child-Safe, Verifikasi Guru Baru, Pengumuman Massal, dan Master Data Playground), serta Pembuat Soal Teka-Teki Mandiri di /app/projects/new.

4. STRICT ANTI-PATTERNS (RED FLAGS 🚩)
- NO LOCALSTORAGE DATA PERSISTENCE: Dilarang keras menyimpan data progres, kelas, atau profil di LocalStorage kustom. Selalu gunakan Supabase PostgreSQL.
- NO DUMMY / INFLATED GRADES: Dilarang memberikan nilai kelulusan palsu/di atas KKM jika murid baru menyelesaikan 1 pulau. Penilaian Rapor WAJIB murni dan transparan sesuai rasio data riil.
- NO BROWSER ALERT POPUPS: Dilarang menggunakan alert() bawaan browser. Selalu gunakan In-App Toast Notification Card yang elegan di dalam UI.
- NO UNLIMITED HINTS: Dilarang membiarkan bantuan Kiko Smart Hint dipakai tanpa batas. Wajib membatasi maksimal 3x per tantangan/pulau agar mendorong anak berpikir mandiri.
- NO HARDCODED / AI TECHNICAL JARGON IN RAPORT: Dilarang menampilkan istilah teknis seperti "Supabase", "PostgreSQL", atau nama model AI pada Rapor PDF resmi siswa. Selalu gunakan Bahasa Indonesia edukatif yang ramah anak.

5. RUNTIME COMMANDS
- Spin up local dev server: npm run dev
- Run unit test suite: npm test
- Build production bundle: npm run build
- Seed Database Rombel Kelas: npm run seed:rombels
- Deploy Serverless AI Edge Functions: SUPABASE_ACCESS_TOKEN=<token> npx supabase functions deploy <nama-fungsi> --project-ref sjmnjoiqrtgxhknbnjyd --no-verify-jwt
