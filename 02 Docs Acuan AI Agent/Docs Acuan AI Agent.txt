# 02 DOCS ACUAN AI AGENT — BLOKUMA VIBE CODING SYSTEM SPECIFICATION
================================================================================

1. RUNNER & SYSTEM BLUEPRINT
--------------------------------------------------------------------------------
Framework      : React 19 + Vite 6 Runner (`vite.config.js`)
Client Router  : React Router DOM v7 (`react-router-dom`, `src/App.jsx`)
Styling        : Tailwind CSS, Framer Motion, Lucide React
State          : Zustand Stores (`src/store/`)
Backend / DB   : Supabase Auth & PostgreSQL (`aws-0-ap-southeast-1.pooler.supabase.com:6543`)
Dev Runner     : `npm run dev` (`vite`) -> http://localhost:3000
Testing        : Vitest (`npm run test`)

2. REPOSITORY & JOURNAL STRUCTURE
--------------------------------------------------------------------------------
/                          : Root bundler & config (index.html, vite.config.js, jsconfig.json, package.json)
public/                    : Static media assets (favicon.svg, Anak.jpg, Register.jpeg)
src/                       : Application root entry (main.jsx, App.jsx, index.css)
src/components/            : Reusable React JSX components (Navbar.jsx, Footer.jsx, StudentSidebar.jsx, UI)
app/                       : Route views (.jsx) grouped into (public), (student), (parent), (teacher), (admin)
engine/                    : Visual Block AST Engine, Rule Engine, Guided Debugger, JS/Python Generators (.js)
services/                  : Real Supabase Client (`lib/supabase/client.js`) & auth service (`services/auth/auth-service.js`)
store/                     : Zustand stores (auth, learning, playground)
supabase/                  : Database migration DDL SQL scripts (`supabase/migrations/20261005000000_initial_schema.sql`)
tests/                     : Unit test suites (Vitest `.test.js`)
03 Jurnal Prompt/           : Standardized 5-Category Prompt Journal (Ide/PRD, Debugging, Audit & Optimasi, Finishing, Bebas)
