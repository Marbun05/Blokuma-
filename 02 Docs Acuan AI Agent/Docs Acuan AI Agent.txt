  - `kiko-story-generator` (Model: `openai/gpt-oss-120b`): AI Storyfication Engine. Menerjemahkan susunan balok koding menjadi dongeng petualangan interaktif yang seru.

## 3. GROUND RULES & ENGINEERING STANDARDS
- Hybrid Single Source of Truth (SSOT & Local-First): Progres kurikulum, kunci jawaban, dan status pulau tersinkronisasi secara instan di LocalStorage dan Supabase PostgreSQL. Apapun kondisi jaringan atau auth user, peta petualangan dan progres koding anak selalu berjalan mulus tanpa hambatan.
- Dynamic Curriculum & Grade Alignment: Materi 6 pulau disesuaikan secara otomatis berdasarkan jenjang kelas anak (SD 1-2, SD 3-4, SD 5-6). Pengaturan kelas di profil siswa menjadi acuan utama untuk menyajikan tantangan dan tingkat kesulitan koding yang presisi.
- Seamless Island Unlocking: Setiap kali anak berhasil menuntaskan misi di sebuah pulau (seperti Pulau 2: Hutan Perulangan), kunci pulau berikutnya (Pulau 3: Gunung Kondisi) langsung terbuka secara otomatis secara realtime tanpa perlu reload browser.
- Audio & Visual Polish: Efek suara audio menggunakan Web Audio API dengan frekuensi terkalibrasi manis (bubble pop) agar terdengar empuk dan menyenangkan di telinga anak-anak. Latar panggung animasi bergerak hanya ketika aksi gerak (`move`) dijalankan.

## 4. STRICT ANTI-PATTERNS (RED FLAGS 🚩)
- NO HARDCODED CLASS OVERRIDES: Dilarang menimpa pilihan kelas siswa dari Pengaturan Profil dengan data statis atau *stale session*. Selalu utamakan preferensi aktif siswa di LocalStorage dan Auth Store.
- NO SILENT PROGRESS LOSS: Dilarang menggantungkan pembukaan kunci pulau hanya pada klik tombol modal. Misi yang tuntas WAJIB langsung menyimpan progres ke LocalStorage & Supabase seketika saat evaluasi berhasil.
- NO HARSH SYNTHESIZED SOUNDS: Hindari penggunaan *frequency sweep* melengking naik untuk efek suara. Selalu gunakan penyesuaian gelombang sinus/segitiga yang lembut dengan *exponential decay* yang ramah di telinga.
- NO RAW EXCEPTIONS: Jangan biarkan *raw exception* atau error teknis terlihat oleh anak. Tangkap error secara elegan dan berikan pesan motivasi dari Robot Kiko.

## 5. RUNTIME COMMANDS
- Spin up local dev server: `npm run dev`
- Run unit test suite: `npm test`
- Build production bundle: `npm run build`
- Deploy Serverless AI Edge Function: `npx supabase functions deploy <nama-fungsi> --project-ref sjmnjoiqrtgxhknbnjyd --no-verify-jwt`
- Execute Database Migration: Gunakan Node.js `pg` client via terminal (`node script.cjs`).
