# BLOKUMA — Adaptive Visual Coding Platform for Primary School Students

"Rancang, Buat, dan Hidupkan Karyamu dengan Kode!"

Blokuma is an adaptive educational visual coding platform built for primary school students (Grades 1–6, ages 6–12).

## Tech Stack
- **Frontend**: Next.js 15 (App Router, TypeScript), Tailwind CSS, Framer Motion, Lucide React
- **State Management**: Zustand
- **Backend & DB**: Supabase (PostgreSQL, Row Level Security)
- **Deployment**: Vercel

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
